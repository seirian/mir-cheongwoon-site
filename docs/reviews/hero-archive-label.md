# 홈 이미지 위 세로 장식 문구 숨김

## 요청 범위
사용자 스크린샷에서 표시한 우측 상단의 `MIR / CHEONGWOON · FAN ARCHIVE` 세로 문구만 수정한다.

## 동작
- `HomeHeroImage`의 기존 `imageReady`와 동일한 상태를 사용한다.
- 이미지가 실제 로딩되어 표시되는 순간 `.promo-art-index`를 렌더링하지 않는다.
- 조회 중·다운로드 중·오류로 이미지가 없는 경우에는 세로 장식을 유지한다.
- 저장된 이미지뿐 아니라 기본 이미지가 표시되는 경우에도 세로 문구는 숨긴다.
- 하단 figcaption, 홈 레이아웃, 관리자 업로드, 이미지 깜빡임 방지 로직은 변경하지 않는다.
- Storage/DB/계정/이미지 파일은 변경하지 않는다.

## 검증
기존 `hero-image-browser-check.py`에 데스크톱·모바일에서 로딩/오류 중 문구 유지,
이미지 표시 후 문구 제거, 하단 소개 유지, 새로고침/홈 재진입 및 동시 노출 방지 검사를 추가했다.
기존 지연 로딩·오류·재시도·기본 이미지 회귀도 유지한다.
실제 운영 검증은 익명·읽기 전용으로 수행하며 계정 로그인이나 업로드를 하지 않는다.
