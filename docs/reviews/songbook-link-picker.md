# 자동 수집 확인: 바로 선택하는 기존 곡 검색

## 사용자 동선
‘정보 확인·연결’에서 검색어를 입력하면 곡명/가수 목록이 바로 나타난다. 별도의 접힌 선택 상자를 다시 열지 않고 펼쳐진 결과를 한 번 눌러 선택한다. 네이티브 select는 size를 항상2이상으로 설정해 드롭다운이 아닌 펼침 목록으로 사용한다. 곡명·가수·저장된 별칭·초성을 검색하며 정확한 제목과 별칭을 우선 표시한다. 같은 제목의 다른 가수나 반주 버전은 별도 ID를 유지한다. 처음에는 후보의 제목으로 검색하며, 목록은8개씩 더 볼 수 있어 예전40개 제한 뒤의 곡도 선택할 수 있다.

결과가 없으면 안내와 ‘새 노래로 등록’을 제공한다. 새 등록은 명시적으로 선택해야 곡명·가수 입력창이 열린다. 수집된 제목/가수는 초안으로 유지하며 검색어를 제목에 덮어쓰지 않는다. 검색어를 변경하면 이전 선택을 해제해 다른 곡에 실수로 저장되지 않게 한다. 곡 선택만으로 서버에 저장하지 않고 마지막 ‘가창 확인 후 반영’에서 승인한다. 선택하지 않은 상태와 사라진 곡 ID는 승인 요청 전에 차단한다. 제외는 곡 선택과 무관하게 가능하다.

## 유지
시:분:초 입력, VOD 새 탭 확인, 패널·페이지·작성 내용 보존, 제외 후 목록 갱신과 안내, 관리자 권한을 유지한다. 외부 전체 음악 DB 검색 기능과는 별개인 기존 노래책 연결 검색이다. DB/Edge/RLS/스케줄 및 실제 곡/숙련도/검토 결정을 변경하지 않는다.

## 접근성과 검증
기본 검색 입력/펼침 목록/버튼으로 마우스와 키보드 선택을 지원한다. 검색창·목록에서Enter를 눌러도 승인하지 않으며 아래 화살표로 결과 목록, 목록에서 기본 위/아래 화살표 선택과Escape로 검색창 복귀를 지원한다. 한글 조합 키는 별도로 처리하지 않는다. 결과 건수와 선택 내용을 상태 메시지로 알린다.

단위 검사: 검색어/별칭/초성/동명곡/빈결과/40개 초과/명시적 선택. 격리된 실제 컴포넌트에서 입력 즉시 펼침 목록·결과 선택·새 곡 등록·키보드·미선택 차단·선택 변경·권한 재검증·VOD 복귀·승인 정수 시간·제외를 검증한다. 기존 모의 인증 검사 파일은 유지하며 새 UI도 기존 곡 선택 계약을 지원한다. 실제 운영은 읽기 전용 검사 후 PR에 결과를 기록한다.
