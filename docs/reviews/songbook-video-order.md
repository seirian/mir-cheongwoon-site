# 노래책 영상 아이콘 표시 순서

노래 목록과 곡 상세에서 사용하는 공통 `vodLinks` 표시 로직을 YouTube → SOOP 순서로 정렬한다. 같은 플랫폼 안에서는 원래 입력 순서와 번호를 유지한다. 연결 주소, 가창 시작 시각, 중복 제거, 새 탭 열기를 보존한다.

저장된 URL 배열이나 자동 가창 이력의 날짜 정렬은 변경하지 않는다. YouTube라는 이유만으로 공식 영상이라고 판정하거나 표시하지 않는다. 기존 곡·난이도·숙련도·관리자 권한·검토 데이터·수집 스케줄에 쓰지 않는다.

회귀 검사: SOOP이 먼저 들어온 혼합 배열, 같은 플랫폼의 안정적 순서, 영상 번호, 서로 다른 시간의 같은 영상, 중복 URL, 빈 목록/단일 플랫폼. 실제 공통 영상 컴포넌트의 목록형/상세형을 네 가지 화면 너비에서 확인하고, 키보드 순서와 새 탭·시작 시각을 검사한다. 기존 GitHub Actions 검증 및 운영 배포 후 읽기 전용 검사를 수행하며 결과는 PR에 기록한다.
