# 노래책 완료 알림 자동 닫기

## 범위
삭제·복원·등록/수정·숙련도 저장·복사 완료와 자동 수집 승인/제외, 음악 정보 가져오기 안내에 공통 알림 훅을 사용한다. 표시 후 10초를 유지하고 300ms 동안 투명해진 뒤 알림만 제거한다. 기존 닫기 버튼은 즉시 사용할 수 있다. 같은 문구가 연이어 발생해도 새 이벤트 기준으로 10초를 다시 시작하며 이전 타이머는 취소한다.

## 보존
오류·권한/조회 경고·직접 복사해야 하는 내용·로딩·검색 결과·삭제 확인 창·입력 폼에는 자동 닫기를 적용하지 않는다. 패널 열림/검색어/페이지/검토 초안은 알림 종료와 무관하다. 곡 상세와 본문에 동시에 나오는 같은 저장 안내는 함께 종료된다. 기존 본문 너비·양쪽 여백과 sticky 위치는 유지한다. 동작 줄이기 설정에서는 페이드 전환을 사용하지 않는다.

타이머는 알림 상태만 변경하며 서버 요청·로그아웃·재수집·삭제/복원 호출을 하지 않는다. 컴포넌트 해제·직접 닫기·새 알림에서 모든 타이머를 정리하고, 오래된 콜백은 이벤트 ID로 한 번 더 차단한다. DB·곡·삭제 상태·권한·스케줄·API 키는 변경하지 않는다.

## 검증
Node 가상 시간 검사로 9999/10000/10300ms 경계, 취소/반복/교체/정리를 확인한다. 기존 운영 모드의 모의 인증/API 브라우저 회귀 검사로 완료 안내·삭제/복원·입력 보존·반응형 여백의 기존 동작을 확인한다. 별도의 신규 가상 시간 브라우저 스크립트 업로드는 도구 보안 상태 판정에서 차단되어 적용하지 않았다. 기존 검사는 비활성화하지 않으며 추가 브라우저 시간 검사를 완료했다고 보고하지 않는다. 기존 전체 CI와 운영 읽기 전용 검사 이후 main에 반영한다. 운영 곡을 시험 삼아 수정/삭제하지 않는다.
