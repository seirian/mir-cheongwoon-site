# 노래책 가창 시작 위치 입력 개선

## 변경
‘확인한 가창 시작 시간 · 초’를 ‘VOD에서 노래 시작 위치’로 바꾼다. 재생바의 `01:12:30` 또는 `03:20`을 그대로 입력하면 승인 요청 직전에 정수 초(4350, 200)로 변환한다. `1:12:30`, `72:30`도 허용하고 입력을 마치면 `시:분:초`로 정리한다. 입력한 위치로 VOD를 새 탭에서 열어 확인할 수 있다.

기존에 저장된 초 값은 시:분:초로 보여주되 원래 값은 변경하지 않는다. 곡별 시작점이 미확인인 구간 목록은 빈 칸으로 유지한다. 빈 칸·잘못된 형식·0~59를 넘는 초/시분초의 분·기존 서버 상한 48시간 초과는 안내하고 승인을 차단한다. 숫자만 입력하는 구방식은 초/분 혼동을 막기 위해 허용하지 않는다. `00:00:00`은 명시적으로 입력한 VOD 시작점으로 허용한다.

## 보존
승인 API의 `seconds` 정수 계약, DB와 RLS, 자동 수집기 및 스케줄, 공개 노래/난이도/숙련도, 기존 관리자 권한은 변경하지 않는다. VOD 새 탭 복귀 시 확인 패널/페이지/작성 중 폼 유지와 항목 제외·완료 알림을 유지한다. 잘못된 시간 입력도 항목 제외를 막지는 않는다.

## 검증
시간 변환/기존값/빈칸/최대 범위/오입력 단위 검사, 실제 컴포넌트의 격리 브라우저 검사, 기존 운영 모드 로그인·승인·제외 브라우저 검사를 실행한다. 승인 요청에 실제 정수 초가 전송되는지 검사하며 입력 도중에는 운영 자료를 수정하지 않는다. 1440/390px와 공개 운영 페이지를 확인하고 최종 CI·배포 링크는 PR에 기록한다.
