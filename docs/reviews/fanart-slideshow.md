# 일정표 팬아트 게시글 이미지 슬라이드

## 요청과 구현
기존 수집기는 선정한 게시글의 본문 첫 이미지만 반환했다. 표지가 미리보기 방지 이미지라면 실제 작품을 볼 수 없었다. 게시글 선정 방식은 유지하고, 같은 게시글 본문 이미지들을 문서 순서로 최대 12장 반환한다. 본문이 있으면 썸네일/작성자/댓글 이미지는 덧붙이지 않는다. 이미지 의미를 자동 판별해 임의 삭제하거나 첫 이미지를 무조건 건너뛰지 않는다.

기존 imageUrl은 첫 이미지로 유지하고 imageUrls/imageCount를 추가한다. 이미지 프록시는 현재 게시글에서 확인된 해시만 허용한다. 12개 고정 캐시 슬롯, 파일별 9MiB 상한, 원본 6MiB 제한, 파일 잠금/원자적 교체/DNS·호스트·MIME 검증을 유지한다. 슬롯에 다른 이미지 ID가 있으면 해당 슬롯만 새로 채운다. 이미지 401/403/429 이후에는 모든 슬라이드의 외부 이미지 조회를 6시간 중단한다.

화면에 보일 때 5초 간격으로 다음 이미지로 전환한다. 약 0.45초 페이드, 이전/다음, 현재 장수, 자동 넘김 일시정지/재시작을 제공한다. 마우스를 올리거나 다른 탭/화면 밖에 있으면 일시 중지하고, 키보드 조작 또는 수동 이동 시 자동 넘김을 멈춘다. 동작 줄이기 설정은 기본 자동재생과 전환 효과를 끈다. 한 장은 정적으로 표시한다. 현재 이미지와 다음 이미지부터 순차 로딩하고, 다음 이미지 준비 전에는 현재 이미지를 유지한다. 개별 실패 이미지는 제외하고 원본 링크/작성자를 보존한다.

## 범위와 제한
일정표 소개 문구·달력 줄바꿈·날짜/필터/편집·메모·홈 PC/모바일 CSS·인증·DB/RLS·업로드 파일·Naver 접근 권한은 변경하지 않는다. 카페 공개 조회 제한을 우회하지 않는다. 기존 배포 백업이 한 장뿐이면 imageUrls 한 장으로 호환 표시하며, 없는 본문 이미지를 만들어 내지 않는다. 외부 조회가 정상일 때 얻은 같은 게시글의 이미지에만 슬라이드를 적용한다. Netlify 호환용 비운영 함수는 변경하지 않는다.

## 검증
Node 입력/순환 검사, PHP 본문 추출·중복·허용 URL·장수 제한·접근 거절·캐시 검사, 실제 PHP 프록시+실제 React 빌드의 격리 브라우저 검사를 수행한다. 1440/390px에서 자동 넘김·수동 순환·일시정지·한 장·구형 캐시·오류·느린 이미지·동작 줄이기·달력 유지 확인. 배포 후 실제 공개 API와 일정표를 읽기 전용으로 검사하고 실제 반환 장수/캐시 여부를 기록한다. 실제 게시물/계정/이미지 업로드는 하지 않는다.
