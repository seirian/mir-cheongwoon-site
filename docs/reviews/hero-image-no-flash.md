# 홈 교체 이미지의 초기 기본 이미지 깜빡임 수정

## 원인과 수정
`HomeHeroImage`가 FALLBACK으로 초기화되어 저장된 이미지의 비동기 조회가 끝나기 전에 기본 캐릭터를 표시했다.
초기 이미지 상태를 비우고, 조회 후 결정된 이미지의 load가 완료될 때만 표시한다. 기존 배경과 영역 크기는 유지한다.
저장된 이미지가 없다는 응답을 받은 경우에만 번들 기본 이미지를 선택한다. 조회 오류나 교체 이미지 다운로드 오류는 기본 이미지로 되돌리지 않고 재시도를 제공한다.
저장 성공은 진행 중인 초기 조회의 버전을 무효화하여 늦은 응답이 새 이미지를 덮어쓰지 않게 한다.
관리자 미리보기도 빈 src를 렌더링하지 않는다. 권한·업로드 경로·DB·실제 저장 이미지·일정표 CSS는 변경하지 않는다.

## 검증
`hero-image-browser-check.py`는 실제 프로덕션 빌드를 대상으로 조회/이미지 응답을 각각 보류한다.
1440/390px에서 초기 기본 이미지 요청 및 DOM 삽입이 없는지, 저장 이미지가 로드된 후만 표시되는지 확인한다.
첫 접속·새로고침·홈 재진입, 미등록 상태, 조회 실패, 이미지 실패/재시도와 기본 파일까지 없는 경우의 무한 루프 방지를 검사한다.
기존 `promotion-browser-check.py`의 레이아웃·카드·일정·관리자 업로드 격리 검사도 유지한다.
`Home hero image verification`은 develop/PR에서 격리 검사를, main 배포 성공 후 읽기 전용 실제 주소 검사를 수행한다.
실제 주소 검사는 기존 교체 이미지가 있는 상태를 전제로 하며 로그인/업로드를 수행하지 않고 쓰기 요청을 차단한다.
실제 파일을 변경하지 않고 브라우저에서 조회와 이미지 읽기만 보류하여 로딩 중의 깜빡임을 확인한다.

## 배포
수정은 develop에서 검증하고 필수 검사와 새 브라우저 검사를 통과한 PR을 통해 main에 배포한다.
실제 저장된 운영/검토 이미지를 교체하거나 삭제하지 않는다.
