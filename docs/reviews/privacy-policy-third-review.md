# 이용자 안내 3차 검토안 · 2026-10-08

## 요청·완료 조건
사용자가 승인한 계정정보 안내 제안을 3차 검토 문안 및 실제 푸터 연결 페이지에 반영한다. 회원정보를 받지 않는 별도 검토 릴리스로 게시하고 데스크톱·모바일에서 확인한다.

기준: feature/privacy-account-review 2da83d3960a5a4703b973750323ac0597c78948d. 기존 검토 브랜치를 이어서 작업하며 main/develop 및 운영 활성화는 변경하지 않는다. 현재 AGENTS.md·architecture.md·harness.md는 앞서 읽은 동일 blob이다. 로컬 clone은 네트워크 DNS 제한으로 실패하여 GitHub API의 정확한 base tree에서 변경하며, 전체 검증은 기존 Node24 Actions에서 수행한다. 실행 전 성공을 선언하지 않는다.

## 채택한 기준
계정 생성·로그인·가입 이메일 검증·비밀번호 재설정에 필요한 아이디·비밀번호·이메일의 수집·이용은 개인정보 보호법 제15조제1항제4호의 객관적 필요성을 전제로 정리한다. 제22조제3항에 따라 항목과 근거를 공개·안내하고 실제 필요성의 입증책임은 운영자가 부담한다. 단순히 필수라고 이름 붙이거나 이용자의 나이를 모른다는 이유로 규정 전체를 면제하지 않는다.

현재 해당 계정 처리에 대한 일률적인 14세 이상 확인, 생년월일·신분증·보호자 정보 추가 수집, 보호자 인증 구축은 가입 조건 또는 필수 출시 과제에서 제외한다. 이후 별도 동의가 필요한 처리를 도입하면 그 처리 전에 제22조의2 등 필요한 절차를 검토·적용한다. 쉽고 명확한 고지와 대리인의 권리행사 안내는 유지한다.

## 화면·문안
- 개인정보처리방침의 수집항목·제3절 처리 근거·제9절 최소 수집·가입 연령, 이용약관의 가입 조건을 정합적으로 수정.
- 승인된 4문장 계정정보 안내를 공통 데이터로 관리하고 가입 시안 및 처리방침에서 재사용.
- 이메일의 홍보·마케팅 미사용을 명시. 개인정보 수집 포괄 동의나 연령 확인 checkbox를 추가하지 않음. 시안의 비활성 checkbox는 이용약관 위치 예시뿐.
- 검토실에 3차 변경 요약을 추가. 문서·푸터·배너·메타데이터·탈퇴 검토 링크를 3차/v0.3로 통일.
- v0.2 원문을 policyContentV02.js에 동일 blob으로 보존. v0.1·v0.2 검토 릴리스는 덮어쓰지 않음.

## 유지한 경계
운영자 옆군/sengyb@naver.com, 탈퇴 시까지 보유·탈퇴 완료 즉시 운영 DB 계정정보 삭제 원칙, 비밀번호 재확인 탈퇴 구현과 모의 UI를 보존한다. 실제 탈퇴 서버는 미배포이며 실회원 삭제 테스트는 하지 않는다.

Supabase·인도 DB·NAVER 문의 메일 등 기존 조사 결과는 인용·승계이며 이번에 재조사한 것으로 표현하지 않는다. 위탁·국외 이전, 실제 SMTP·호스팅 사업자·재위탁 국가, 로그·메일·백업 보존기간과 실제 탈퇴 연동 검증은 별도로 남는다. 제15조 근거로 이를 일괄 면제하지 않는다. 친목단체 예외 여부는 기존 검토 구분을 유지하며 이번 결론의 전제로 삼지 않는다.

## 검증 계획
기존 전체 npm run verify / check:backend / Deno entry check / 합성 AccountPage UI 및 탈퇴 검토 검증을 유지한다. 정책 브라우저 검사에 3차 표시, 처리 근거, 홍보 미사용 문구, 연령 추가 입력 없음, 아동 절의 필수 출시 확인 배너 제거, 목차·가입고지·푸터 경로를 추가한다. 로컬/공개 검토 릴리스 모두 검사하고 스크린샷을 확인한다. 검증 결과와 URL은 Actions reports의 실제 값으로만 보고한다.
