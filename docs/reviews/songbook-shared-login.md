# 노래책 중복 편집 로그인 제거

## 요청과 변경 범위
노래책의 별도 ‘편집 로그인’ 버튼과 로그인 모달을 제거한다. 기존 사이트 하단 ‘로그인 / 회원가입’ 또는 `/account/`에서 아이디·비밀번호로 로그인하는 동선을 사용한다.

사이트 공통 세션과 `useSongbookStore`의 권한 판정은 변경하지 않는다. 기존 관리자 또는 노래책 편집 권한이 있는 계정에는 노래 추가·곡 정보 편집이 표시된다. 미르님 숙련도는 기존 owner 계정만 변경할 수 있다. 일반 회원과 비로그인 방문자에게 편집 권한을 추가하지 않는다. 로그인한 계정의 기존 권한 연결·로그아웃 버튼은 유지한다.

계정 인증 코드, DB 스키마, RLS, 계정 권한, 노래 데이터, 일배치 및 외부 음악 검색은 수정하지 않는다. 과거 검토 릴리스를 덮어쓰지 않는다.

## 검증
- Node 회귀 검사: 노래책 로그인 진입점/모달 제거, 공통 계정 로그인 유지, 편집 버튼 권한 조건 보존.
- 격리된 운영 브라우저: 기존 계정 페이지의 로그인 실패·성공, 관리자 추가·편집, 일반 회원 읽기 전용, owner 숙련도 저장, 새로고침·공통 로그아웃, 모바일/데스크톱 레이아웃.
- 실제 운영 읽기 전용 검사: 중복 버튼 없음, 공통 로그인 이동, 익명 편집 차단, 활성 릴리스·운영 DB 조회·한국어 검색 유지.

성공 로그인 및 쓰기 검사는 모의 인증/API만 사용한다. 실제 운영 검사는 로그인·데이터 쓰기를 하지 않는다. 최종 실행 결과와 병합·배포 SHA는 PR에 기록한다.
