# 노래책 운영 화면·관리자 권한·미정 난이도 보완

## 요청 및 화면 변경
노래책 전용 관리자/계정 연결/로그아웃 버튼과 상단 ‘노래 찾아보기’를 제거했다. 기존 사이트 아이디·비밀번호 로그인 및 공통 계정 메뉴는 유지한다. 노래책에는 권한이 있는 관리자의 ‘노래 추가’와 곡 상세의 편집 기능만 남긴다.

운영 편집 권한은 기존 `admins` 등록 여부만 사용한다. 별도 노래책 owner/manager 등록이나 UUID 연결은 필요 없다. 곡 정보와 미르님 숙련도를 같은 관리자 권한으로 등록한다. 일반 회원, 비로그인 방문자, 기존 노래책 역할만 있는 비관리자는 수정할 수 없다. 숙련도는 미르님의 평가를 입력하는 항목이며 외부 자료로 자동 생성하지 않는다.

운영 `songbook_entries`/`songbook_ratings`의 INSERT·UPDATE 네 RLS 정책도 동일하게 적용했다. 기존 관리자를 추가하거나 계정의 권한을 변경하지 않았다. 기존 `songbook_editors` 및 검토 전용 테이블은 삭제하지 않았고, 운영 클라이언트는 별도 편집자 테이블을 조회하지 않는다. 정책 적용 SQL은 `supabase/ops/songbook_admin_access.sql`에 기록했다.

## 난이도 조사 결과
2026-10-04 KST 기준 정적 카탈로그 342곡 중 기존 평가 49곡을 보존하고, 난이도 미정 **293곡 전부**를 수집한 공개 가창 난이도 자료와 대조했다.

- 명시적인 난이도 표시가 있는 외부 평가 **24,559건**을 확보했다. 숙련도·악보 연주 난이도는 가져오지 않았다.
- 90개 공개 노래책 표본을 확인했고, 초기 평가 분포를 통과한 43개 목록의 모든 페이지를 확인했다. 모든 인터넷 자료나 90개 목록 전체 페이지를 조사했다는 뜻은 아니다.
- 최종 분포가 단일 점수, 1점 70% 초과 또는 특정 점수 90% 초과인 19개 목록은 초기값 가능성을 배제하기 위해 참고에서 제외했다. 이 기준만으로 해당 목록의 실제 작성 의도를 단정하지 않는다.
- 같은 곡으로 확인하고 평가를 사용할 수 있었던 **90곡을 추가 설정**했다. 기존 49곡과 합쳐 **139곡에 난이도**가 있다.
- 남은 **203곡**은 같은 곡의 신뢰 가능한 평가를 찾지 못한 151곡, 평가 충돌 47곡, 단일 1점만 확인된 5곡이다. 평가를 추정해서 채우지 않았다.

일치 판정은 곡명/가수와 기존에 함께 표기된 다국어 별칭을 사용한다. 제목만 비슷하거나 악곡 버전이 다르면 자동 합치지 않는다. 각 노래책은 곡당 한 표로 계산하며, 같은 목록의 충돌 평가도 제외한다. 평가 범위가 2점 이내이면 중앙값을 반올림하고, 더 넓으면 3표 이상이며 동일 점수가 2/3 이상일 때만 그 점수를 사용한다. 참고 난이도는 편곡·키·가창자에 따라 달라질 수 있고 관리자가 수정할 수 있다.

## 근거와 재현
293곡 각각의 반영/보류 사유와 참고 항목은 `songbook-difficulty-audit.json`에 보관한다. 이 파일은 src/public에 넣거나 화면에서 불러오지 않는다. 공개 모델에는 기존과 같이 곡 ID별 점수만 반영되며 수집 사이트명·원본 출처·타인의 숙련도는 포함하지 않는다.

- https://github.com/seirian/mir-cheongwoon-site/actions/runs/37131104709

`12bc9a8433a2e1a0b5d6bb890ffd6ffcc700b97cab54857a5638f584a7b98427`

`python scripts/reconcile-songbook-difficulty.py --self-test`로 알고리즘을 확인한다. 재현 시 감사 JSON의 `preserved_ratings`를 별도 JSON 파일로 저장한 뒤, 원본 artifact 폴더를 `--reference-dir`, 49개 기존 점수 JSON을 `--baseline`으로 전달한다. `--write` 없이는 파일을 변경하지 않는다. 이 스크립트는 네트워크 접근·실시간 수집·자동 배치를 수행하지 않는다.

`src/data/songbookDifficulty.json` 수정 후 기존 `prepare-songbook-v2.mjs`가 공개 카탈로그를 생성한다. 저장된 관리자 수정값은 정적 참고 난이도보다 우선한다. 기존 평가 49곡, 미르님 숙련도, 운영 곡 데이터와 일배치는 자동 변경하지 않았다.

## 검증
Node 회귀 검사는 미정293곡 전체의 대조 상태, 기존49개 보존, 반영90개 및 미정203개, 점수 산출 근거, 관리자의 기존 수정값 우선, 숙련도 미생성을 확인한다. 운영 방식의 격리된 브라우저에서 관리자/일반 회원/과거 owner·manager와 공통 로그인/로그아웃을 구분한다. 별도 PostgreSQL17에서 실제 RLS 정책으로 관리자 수정 허용과 비관리자 수정 거부를 확인한다. 운영 주소 검사는 읽기 전용으로 수행하며 실제 비밀번호·곡 수정은 사용하지 않는다.

이번 변경은 별도 공개 검토 버전 없이 develop → main으로 반영한다. 최종 테스트·병합·배포 실행과 활성 릴리스는 PR #80에 기록한다.
