# 실제 미리보기 검증에서 보완한 회귀 사례

- 개천절 등 달력용 기념일은 전체 달력에 유지하되 홈의 다음 아티스트 활동에서 제외합니다. 기념일 테마의 실제 방송·콘서트는 제외하지 않습니다.
- 호스트 브리지의 내부 경로가 디렉터리 리다이렉트에 노출되지 않도록 release 범위에서 DirectorySlash/AllowNoSlash와 정적 문서 재작성을 처리합니다. 디렉터리 목록은 차단합니다.
- clean URL·끝 슬래시·index.html 직접 접근을 확인하며 브라우저 검증은 H1과 최종 URL도 비교합니다. HTTP 200이나 noindex만으로 잘못된 홈 이동을 성공으로 판단하지 않습니다.
- 실제 운영 라우팅이나 기존 release는 수정하지 않고 새로운 staged-only release로 확인합니다.
