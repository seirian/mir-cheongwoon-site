# 자동 수집 확인: 작업 상태 유지와 대기열 정리

## 요청과 완료 조건
VOD를 새 탭에서 확인한 뒤 돌아오거나 항목을 제외해도 펼침·탭·현재 페이지·작성 중 폼을 유지한다. 서버에서 제외에 성공한 항목만 화면에서 제거하고 목록을 다시 채우며 완료 안내를 표시한다. 실패 시 항목을 그대로 두고 오류를 알린다.

## 원인과 수정
같은 계정의 SIGNED_IN/TOKEN_REFRESHED에도 관리자 상태를 false로 초기화해 관리자 패널이 해제되던 흐름을 수정한다. 같은 사용자 재검증 중에는 검증된 화면을 유지하되 모든 편집은 중지한다. 계정 변경·실제 로그아웃·검증 실패·관리자 권한 회수는 즉시 권한을 제거한다. 서버 RLS나 JWT 검증은 완화하지 않는다.

패널의 펼침·탭·페이지는 계정별 sessionStorage에 저장한다. 토큰·댓글·후보 데이터는 저장하지 않는다. 목록 요청은 세대 번호로 오래된 응답을 무시하며 마지막 페이지가 비면 직전 페이지로만 이동한다. VOD는 새 탭으로 열고, 외부 창 복귀 및 열린 화면의 30초 주기로 해당 목록만 재조회한다. 편집 중인 폼은 주기 조회에서 보호한다.

## 대기열 정리 원칙
현재 공개 타임라인의 앞뒤 문맥을 다시 대조한다. 게임 라운드/소통/레슨 설명, 축하 영상과 다른 출연자 공연 감상 등 명확한 비가창 항목만 자동 제외한다. 이미 노래책에 등록된 곡이면서 곡별 시간이 없는 구간 목록은 중복 검토 대상으로 별도 분류한다. 이는 미르님이 부르지 않았다는 판정이 아니다.

불명확한 가창·신규 곡·부분 가창·새 작성자라는 이유만으로 일괄 삭제하지 않는다. 제외 항목은 물리 삭제하지 않고 자동 제외 기록에서 확인·승인할 수 있게 보관한다. 사용자가 승인하거나 제외한 결정과 수동 곡·난이도·숙련도는 보존한다. 신규 판별 규칙은 다음 수집에도 적용한다.

## 검증
순수 상태/분류 회귀 검사, 기존 전체 CI, 격리 인증/API 브라우저의 새 탭·복귀·토큰 갱신·연속 제외·마지막 페이지·실패·권한 회수 검증을 수행한다. 운영에서는 실제 계정 비밀번호를 사용하지 않고 공개 페이지를 읽기 전용으로 확인한다. 실제 정리 건수와 최종 실행/배포 결과는 PR에 기록한다.
