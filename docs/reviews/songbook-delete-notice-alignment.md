# 삭제 완료 알림 좌우 정렬 수정

## 원인과 변경
페이지 알림은 `section-wrap sb-delete-notice sb-auto-notice`를 함께 사용한다. 공통 알림의 `margin:16px 0`이 본문의 `margin-inline:auto`를 덮어써, 너비는 제한되지만 화면 왼쪽에 붙어 표시됐다. `sb-delete-notice.section-wrap`에만 `margin-inline:auto`를 지정해 노래책 본문과 같은 너비·좌우 여백을 재사용한다. 고정 픽셀 너비나 뷰포트 비율을 새로 넣지 않으며, 모달 내부 복원 알림 및 자동 수집 검토 알림의 레이아웃은 변경하지 않는다.

## 검증
기존 CSS를 사용하는 로컬 재현에서 1920px 화면의 알림 왼쪽은 0px, 본문은 300px였고 수정 후 양쪽 모두 300px로 일치했다. 기존 운영 모드 삭제 브라우저 검사에 320/390/768/1024/1440/1920/2560px의 삭제·복원 완료 알림 경계 비교와 긴 문구 줄바꿈·닫기 버튼·가로 넘침 회귀를 추가한다. 기존 확인·삭제·복원·권한·통신 실패 검사를 유지하고 GitHub Actions에서 최신 전체 소스로 실행한다. 실제 운영 데이터는 시험 삼아 삭제·복원하지 않는다.

UI 스타일 및 검사만 변경한다. DB·곡 정보·삭제 상태·권한·자동 수집/일배치/Discord 스케줄·API 키 변경 없음. develop 검증 후 main PR 및 기존 운영 배포 절차를 사용하며 최종 실행 결과는 PR에 기록한다.
