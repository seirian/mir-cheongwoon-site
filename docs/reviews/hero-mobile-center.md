# 모바일 홈 이미지 중앙 정렬

## 요청과 수정 범위
모바일에서 업로드 이미지가 우측으로 치우치는 문제를 수정하고 develop → main으로 배포한다. PC 화면은 변경하지 않는다.
원인은 기존 800px 이하 이미지의 `right:0`, `object-position:bottom right`와 78%/86% 너비 조합이다.
`promotion-v2.css` 끝에 홈 portrait만 대상으로 한 800px 이하 규칙을 추가한다. 이미지 박스와 내부 콘텐츠를 수평 중앙에 두되 기존 너비·높이·contain·하단 기준은 유지한다.
PC, 캡션, 관리자 업로드, 이미지 로딩/세로 문구 상태, 일정표, 저장 파일·권한·DB는 변경하지 않는다.

## 검증
- 기존 문법·41개 단위 테스트·빌드 및 이미지/관리자 업로드 회귀 검사를 유지한다.
- 이전 배포 4cdb1d56의 promotion-v2.css만 사용한 비교 빌드를 만든다. 나머지 코드는 후보와 같다.
- 320/360/390/412/430/520/640/768/800px에서 수평 중앙과 기존 이미지 크기, 캡션·주변 배치 유지 확인.
- 801/1024/1440/1920/2560px에서 이전 CSS 빌드와 모든 hero 치수·관련 computed style 및 hero 스크린샷이 동일한지 비교한다.
- 정사각형·세로형·가로형 PNG fixture를 브라우저 요청에만 공급하여 다양한 비율의 object-position도 검사한다. 서버에 업로드하지 않는다.
- 배포 후 실제 저장 이미지를 읽어 같은 중앙 정렬을 확인한다. 이전 운영 release와 PC 치수를 비교한다. 실제 운영은 동적 데이터이므로 픽셀 동일성 검사는 격리 빌드에서 수행한다.
- CSS baseline은 이전 승인본으로 고정되어 있다. 추후 의도적인 hero 디자인 변경 시 검토 후 baseline을 갱신한다.
