# 노래책 3차 검토

## 범위와 완료 조건
feature/songbook에서만 개발하고 검토용 릴리스만 스테이징한다. main/develop 병합 및 운영 라우팅 전환은 하지 않는다.

- 제목 옆에 모든 YouTube/SOOP VOD 링크를 플랫폼별 아이콘과 번호로 표시한다. 각 링크는 새 탭으로 열며 알려진 시작 시간을 유지한다.
- 곡 제목 왼쪽에는 선택한 앨범 이미지, 연결 YouTube 영상 썸네일, 기본 음악 아이콘 순으로 사용할 수 있는 이미지를 표시한다. 영상 썸네일은 VOD라고 구분한다.
- 노래 추가의 검색 범위는 기존 목록에 국한하지 않는다. 로컬 등록 곡 확인과 외부 음악 DB 검색을 병행하며 서로 다른 영역으로 표시한다.
- 자동 검색은 iTunes 한국/미국/일본과 MusicBrainz를 조회한다. 특정 국가 선택과 Apple Music 곡 주소를 통한 ID 조회도 제공한다. 미유통/미등록곡 등 모든 노래가 존재한다고 주장하지 않는다.
- 2026-10-02 실제 조회에서 영물이다는 한국 0건, 미국/일본에는 Wisp! (이오몽/Lee Omong)으로 반환됐다. 특정 곡의 응답을 하드코딩하지 않는다. 사용자가 가수와 앨범을 확인해 가져오고 한글 별칭을 명시적으로 추가할 수 있다.
- 새로운 UI와 CSV 및 JS 번들에 수집용 팬 사이트 식별자와 원본 출처 데이터가 포함되지 않게 유지한다. 이미지 제공 음악 서비스의 필요한 상점 연결은 별개다.

## 자료와 안전
음악 서비스 메타데이터는 제목, 가수, 앨범, 공식 연결 주소, 커버 이미지에 한정한다. 가사·오디오를 복사하지 않는다. 해외 이름을 자동으로 번역해 실제 곡과 일치한다고 확정하지 않으며 사용자 확인 후 등록한다. 외부 노래를 찾아도 미르님의 기존 레퍼토리나 가창 사실로 자동 등록하지 않는다.

PHP 검색은 제한된 고정 HTTPS 엔드포인트에만 요청한다. 사용자 주소 자체를 가져오지 않으며 음악 서비스 곡 ID만 추출한다. curl_multi로 병행 요청, 제공자별 속도 제한, 제한된 응답 크기·타임아웃, 6시간 성공 캐시/5분 빈 결과 캐시/30초 부분 실패 캐시를 적용한다. 완전한 검색 실패는 0건 성공으로 처리하지 않는다.

이미지·음악 연결 주소는 허용 호스트/경로를 검증한다. 앨범 아트는 관련 상점 링크를 함께 표시한다. 이미지 로딩 실패는 기본 아이콘으로 대체한다. 원격 임의 이미지 프록시는 없다.

## 저장
기존 검토 전용 songbook_preview_entries에 artwork_url, music_url, album_title을 추가하고 SOOP VOD 시작 시간 검증을 확장했다. 운영 콘텐츠 테이블과 일배치는 변경하지 않았다. 소유자 숙련도와 편집자 권한은 기존 RLS를 유지한다. 체험 모드 값은 localStorage에만 저장한다.

SQL 검증은 임시 사용자와 곡으로 이미지/다중 영상 저장, 수정 버전 증가, 잘못된 이미지 거부, 일반 관리자 숙련도 거부, 익명 수정 거부를 확인한 후 전체 트랜잭션을 rollback한다. 미르님 소유자는 임의로 지정하지 않는다.
