# 관리자 연결 영상 유무 검색

## 요청과 사용
노래책 난이도 조건 아래에 관리자 전용 ‘연결 영상 조건’을 추가한다. YouTube와 SOOP 각각 전체/있음/없음을 선택하며, 두 조건은 AND로 조합한다. YouTube 없음 + SOOP 전체는 유튜브 보완 대상, YouTube 없음 + SOOP 있음은 숲 영상만 있는 곡, 둘 다 없음은 연결 영상 없는 곡이다.

기존 곡명·가수·초성·카테고리·난이도·즐겨찾기 조건 및 정렬과 함께 적용한다. 전체 결과를 먼저 필터링하고 건수·페이지·CSV가 같은 결과를 사용한다. 조건 변경은 첫 페이지로 돌아가고, 영상 조건 초기화는 다른 검색어/조건을 유지한다. 기존 전체 초기화는 영상 조건도 지운다. URL에 조건을 저장하므로 상세 편집·새로고침·뒤로 가기 후 유지되며, 편집으로 영상을 추가하면 ‘없음’ 결과에서 해당 곡만 빠진다.

## 판정·권한
기존 아이콘과 동일한 vodInfo로 정규화된 videoUrls를 판정한다. 기본·직접 등록과 자동 수집으로 병합된 영상 모두 대상이다. Apple 앨범 링크/커버만 있거나 채널 페이지인 경우는 영상으로 세지 않는다. 공식 영상이나 실제 재생 가능 여부를 조회·보증하는 기능은 아니다. 자동 영상 조회가 실패하면 현재 불러온 링크 기준이라는 안내를 표시한다.

기존 서버에서 확인한 store.admin인 경우만 UI와 필터를 활성화한다. 비로그인/일반 회원은 URL에 youtube/soop 조건이 있더라도 무시한다. 권한 확인 중에는 기존 검증 UI를 유지하고 선택을 잠시 비활성화한다. 새 권한·인증 예외·서버 API는 만들지 않는다.

## 검증·범위
9개 Node 검사: 9가지 조합, URL 형식·거짓 호스트, 비관리자·잘못된 조건 무시, 자동 링크·기존 조건·페이지·CSV·편집 후 재필터링. 운영 모드 앱의 격리된 모의 인증/API 브라우저 검사로 전체 조합, 페이지2, CSV, 새로고침/뒤로가기/초기화, 실제 편집 흐름 및 비관리자/로그아웃, 모바일/데스크톱을 확인한다. 기존 Actions 검사를 유지하고 운영 배포 뒤 읽기 전용 점검을 진행한다. 최종 SHA와 실행 결과는 PR에 기록한다.

로컬 원본은 이전 첨부 snapshot이며 이번 수정 대상 page를 최신 GitHub blob과 일치시켰다. 로컬 단위 검사는 실행하되 최종 전체 소스/빌드/UI 검증은 최신 develop 기준 Actions에서 수행한다. DB·등록곡·삭제 상태·숙련도·검토 결과·자동 수집/일배치·Discord·API 키는 직접 변경하지 않는다. 운영 사용자 곡을 시험 삼아 수정하지 않는다.
