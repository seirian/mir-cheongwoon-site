# YouTube 키워드 검색 연결 작업

## 목표
등록한 GitHub Secret으로 검토용 PHP 서버의 공식 YouTube 검색을 활성화한다. 사용자가 복사한 영상 URL뿐 아니라 검색 결과에서 바로 영상을 선택할 수 있어야 한다. 운영 배포나 실제 곡 데이터 쓰기는 하지 않는다.

## 완료 조건
Secret 존재 여부 확인, 서버 전용 키 전달, 공개 다운로드 차단 및 0600 권한, 송신 IP 확인, 공식 검색의 실제 결과와 가수 공란 가져오기/로컬 저장, Apple 검색 유지, Melon 숨김, 실패 시 안전한 오류/설정 정리, 기존 브라우저 회귀.

## 검증
PHP 키 형식·경로·권한·오류 매핑 검사와 Python 메모리 SFTP 검사. 기존 Verify 및 운영 모드 회귀, 새 검토 워크플로의 격리/공개 브라우저 검사. API의 새 키워드 검색은 12개 이내 결과와 빈 가수 필드를 확인한다. Google 프로젝트의 키 제한 설정 자체는 접근 권한이 없어 별도 확인 대상이며 송신 IPv4를 제공한다.

## 서버 비밀 설정
키는 프로비저닝 단계에서만 읽으며 빌드나 브라우저로 전달하지 않는다. 가능한 경우 SFTP 홈의 .mir_songbook_keys(0700)에 릴리스별 0600 PHP 파일로 보관한다. 공유 호스팅 제한으로 불가능하면 실제 공개 URL 및 별칭의 403/404 차단을 먼저 검증한 API 내부 비공개 PHP 파일을 사용한다. 생성한 파일은 직접 실행 시 404로 종료하며, 실패 시 이번에 만든 설정만 정리한다. 기존 파일은 덮어쓰지 않는다.

PHP 서버 송신 IPv4는 인증된 일시 진단으로 확인하고 진단을 제거한다. Google 호출은 고정 HTTPS 엔드포인트, IPv4, X-Goog-Api-Key 헤더를 사용하며 키가 URL에 포함되지 않는다. 실제 API/IP 제한 값은 키 문자열만으로 조회·변경할 수 없으므로 확인한 주소로 Google Cloud에서 제한을 적용할 수 있다.

기존 24시간 80회 미캐시 키워드 조회 예산 및 5분 결과 캐시를 유지한다. 조회 오류는 허용된 코드로만 안내하며 upstream 원문 메시지나 헤더를 반환하지 않는다. Melon 주석, 운영 라우팅·DB·계정·권한·수집 스케줄을 보존한다. 검토 결과는 PR #90에 기록한다.
