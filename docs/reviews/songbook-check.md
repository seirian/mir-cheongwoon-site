# 노래책 사용성 3차 검토

## 이번 요청 / 완료 조건
`feature/songbook_check`에서만 2차 검토 화면을 보완한다. 영상 버튼의 ‘대표 영상’ 문구와 별표를 제거하고 기존 YouTube/SOOP 플랫폼 아이콘·이름으로 표시한다. 각 영상 링크 우측 외부 이동 화살표를 제거한다. 곡 목록에서 카테고리 왼쪽, 영상 버튼 오른쪽을 같은 가로 행에 배치한다. 기존 GitHub Actions의 stage-only 흐름으로 새 검토 주소를 만들고 develop/main·운영 라우팅은 변경하지 않는다.

## 3차 변경
- 목록과 상세의 영상 버튼은 같은 플랫폼 표기와 번호를 사용한다. 대표 표시용 별표·강조·문구, 영상/주소 링크의 우측 화살표를 표시하지 않는다. 공유 동작은 없애지 않고 화살표 대신 링크 복사 아이콘으로 구분한다.
- 내부 첫 유효 YouTube 선택 정책, YouTube→SOOP 정렬, 같은 플랫폼 안의 기존 URL 순서·번호·타임스탬프는 유지한다. 영상 용도와 실제 공식/가창자 판정은 바꾸지 않는다.
- 카테고리 배지와 영상 버튼을 하나의 flex 행으로 구성한다. 영상 버튼 그룹은 줄바꿈하지 않고 카테고리 오른쪽에 놓는다. 좁은 화면에서는 해당 행이 카드 가로폭을 사용하며, 여러 카테고리의 텍스트만 자기 영역 안에서 줄바꿈한다. 카테고리를 숨기거나 잘라내지 않는다.
- 기존 목록의 두 영상 미리보기와 나머지 `+N` 표시를 유지하며, 곡 상세에서는 모든 링크를 볼 수 있다. 모바일 영상/복사/공유/즐겨찾기 조작 영역은 높이 44px 이상이다.
- 빠른 수정에서는 연결 영상/YouTube 우선 안내로 표시하고 대표 배지를 제거한다. URL 추가·제거·저장 후 다음 곡, 이전 브라우저 변경, 상태/검색/카테고리/별점 데이터는 보존한다.
- 페이지·HTML·검토 안내·배포 메타데이터를 3차로 표시한다. 1·2차 정적 릴리스는 덮어쓰지 않는다.

## 검증 계획과 경계
기존 회귀 검사에 플랫폼 버튼 표기/화살표 부재, 카테고리 오른쪽 같은 행 정렬, 시청자/관리자 320/390/768/1440/1920px, 빈 영상/복수 카테고리 및 20개 링크의 상세 보존 검사를 추가한다. 첫 YouTube 선택과 추가/제거/타임스탬프·저장 실패·검토 저장소 분리 검사를 유지한다. 기존 정적 버전 확인은 현재 3차 번호로 갱신한다.

로컬은 Actions의 정확한 `6aadfa78` 소스 아카이브(tree `80529fa90a4f1f673ec72d4fdb0f162d3e409491`)에서 시작했다. Node22 단위·빌드/문법 검사 후 Node24 전체 검증과 브라우저 검사는 기존 Actions에서 실행한다. 로컬 Chromium의 첫 탐색은 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 로컬 브라우저 통과로 보고하지 않으며 정책·실행 플래그를 변경하지 않는다. Actions의 기존 CI 내부/공개 검토 검사는 원래 배포 절차대로 수행한다. 최종 결과와 공개 주소는 PR #99에 기록한다.

검토 화면은 여전히 공개 운영 목록의 빌드 시점 사본이다. 로그인 없는 관리자 체험은 실제 권한이 아니며 편집은 전용 브라우저 저장소에만 남는다. 운영 API 호출·서버 데이터 쓰기·운영 App/AuthProvider/songbookStore 포함을 차단하고, `.htaccess` 운영 라우팅 지문이 배포 전후 동일함을 확인한다. 실제 운영 곡·권한·삭제·숙련도·자동 수집/일배치·API 키는 변경하지 않는다.
