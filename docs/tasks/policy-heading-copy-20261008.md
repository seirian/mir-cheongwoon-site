# 공개 정책 제목 아래 소개 문구 제거 · 2026-10-08

사용자가 지정한 개인정보처리방침·이용약관·운영정책의 소개 문장 3개를 공개 화면에서 삭제한다. 공통 PublishedPolicyPage의 lead 문단을 제거하며 빈 문단이나 대체 홍보문을 넣지 않는다. 제목·버전·최초 공개일·목차·본문·위탁표·푸터·가입/탈퇴·DB는 변경하지 않는다. 기존 검토본 및 데이터의 정책 내용도 수정하지 않는다.

기준 main/develop: 7297eb69b3a079ff68e2dd9b202274f1d0bcef2e. GitHub 연결과 기존 Actions를 사용하며 원격 PC는 사용하지 않는다. 로컬 clone의 DNS 실패는 GitHub 권한과 무관하므로 정확한 base tree에 최소 파일 수정만 커밋한다.

회귀 테스트 2개와 기존 공개 UI 검사에 소개 문구 및 빈 lead 영역 부재, 제목·메타 유지, PC/모바일 직접 열기·새로고침·푸터 이동 검사를 추가했다. 세 문서의 상단 화면을 별도 캡처한다. 전체 verify/check:backend 및 정책 브라우저 검사를 통과한 뒤 develop → main PR을 merge commit으로 병합하고 기존 운영 배포와 실제 주소의 검사 결과를 확인한다. 실행되지 않은 검증을 완료로 보고하지 않는다.
