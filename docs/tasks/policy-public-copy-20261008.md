# 공개 정책의 내부 검토 안내 분리 · 2026-10-08

## 사용자 확인 완료
운영자가 정할 기준은 앞선 승인으로 확정됐다. 옆군/sengyb@naver.com, 계정 탈퇴 시까지 보유 및 운영 DB 즉시 삭제, 현재 비밀번호 재확인, 문의 종료 후 불필요한 기록 파기, 관리자 자료·권한 인계 후 탈퇴, 가입 연령정보 추가 수집 없음은 재확정을 요청하지 않는다.

## 이번 수정
사용자가 공개 페이지의 추가 확인 안내가 불필요하다고 지적했다. 운영용 PublishedPolicyPage에서 세 개의 `처리 범위와 추가 확인 안내` 박스를 제거한다. 내부 점검·준법 보증 부인 등 검토 메모를 사용자에게 반복해서 표시하지 않는다. 기존 정책 데이터의 note 필드는 변경 이력과 소스 검토용으로만 남기며 운영 렌더러에서 읽지 않는다. 별도 검토 릴리스와 PolicyPage는 수정하지 않는다.

계정 즉시 삭제가 외부 서비스의 모든 로그·백업 사본까지 의미하지 않는다는 실제 처리 범위는 보유·파기 절의 보통 문단으로 유지한다. 위탁·국외 이전 표와 확인되지 않은 업체/국가/기간은 그대로 두어 미확인 사실을 확정된 것으로 바꾸거나 실제 외부 처리를 숨기지 않는다. 개인정보 처리범위, 권리, 보유기간, 가입 동의, 탈퇴 함수/DB, 배포 권한은 변경하지 않는다. 표현·배치 정리이며 정책 버전과 최초 공개일을 바꾸지 않는다.

## 남은 사항의 책임 구분
사용자의 운영정책 결정 완료와 실제 서비스 설정 검증 완료는 다르다. 호스팅 계약상 법인·SMTP·재위탁/처리국가·로그/백업 주기 확인과 실제 탈퇴 E2E는 기존 기술 점검 기록에 남는다. 이번 UI 수정이나 공지 삭제가 해당 작업 완료 또는 준법 보증을 뜻하지 않는다. 운영자의 실명은 공개하지 않는다.
