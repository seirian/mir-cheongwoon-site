# 목록형·커버형 2차 검토안 운영 반영

## 승인 범위
사용자가 PR #103의 최종 2차 검토안(53620021)을 승인하고 develop/main 반영 및 운영 배포를 요청했다.
기존 main/develop은 4b42ef36이며 backup_20261007은 bc1cea3e에 그대로 보존한다.
승인한 화면을 변경하지 않고 기존 운영 경로의 실제 DB/공통 인증과 연결된 코드를 승격한다.
독립 검토용 사본·인증 대체 모듈은 전용 Vite 설정에서만 사용되며 운영 빌드에는 적용하지 않는다.

## 유지할 기능
- 최초 방문 목록형, 10/25/50/100곡(기본25). 브라우저에서 선택한 보기 방식은 유지한다.
- 커버형은24/48/96곡(기본24), PC6열·태블릿4열·모바일2열. 불필요한 상세 안내 문구는 제거된 상태를 유지한다.
- 커버/곡명 상세, 모든 카테고리, 참고 난이도, 영상, 즐겨찾기와 공통 관리자 편집·일괄 상태 변경을 유지한다.
- 보기 전환은 필터/정렬 보존, 해당 보기 기본 표시수/첫 페이지 이동, 관리자 체크 선택 해제.
- 검토 페이지의 보기/즐겨찾기 데이터는 운영으로 가져오지 않는다.

## 배포 절차와 검증
PR #103을 develop에 merge commit으로 반영한다. 운영 읽기 전용 커버 검사만 추가한 뒤
최신 develop→main PR의 Verify 세 작업과 Develop promotion 및 전체 격리 브라우저/DB 검사를 통과시킨다.
main 반영은 merge commit으로 진행하고 develop을 main으로 fast-forward 동기화한다.
기존 Deploy mir.yeop.net Actions와 후속 Songbook live verification을 사용한다.

새 읽기 전용 검사는 운영 릴리스 SHA, 최초 목록25, 커버24/48/96, 다음/이전/새로고침,
필터 유지, 잘못된 표시수, 상세 열기, 보기 선호 저장소 분리,6열4행/4열/2열을 확인한다.
테스트 브라우저의 보기 설정만 변경하며 로그인·관리자 저장·실제 곡 상태 변경을 하지 않는다.
서버 변경 메서드 및 검토용 사본/테이블 요청은 보내기 전에 차단하고 실패로 기록한다.
기존 운영 검사와 합쳐 실제 화면 캡처/JSON 보고서를 Actions 아티팩트로 보존한다.

복구할 수 있으며, 실제 복구는 별도로 판단한다. 최종 커밋/배포/검증 결과는 운영 PR에 기록한다.
